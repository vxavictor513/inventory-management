Request Data Flow

1
User interacts with FilterBar Selects Time Period, Location, Category, or Order Status. Values stored in useFilters composable refs (selectedPeriod, selectedLocation, selectedCategory, selectedStatus).
2
View component calls API Calls getCurrentFilters() which returns a params object. Component passes this to the relevant function in api.js (e.g. api.getOrders(filters)).
3
api.js builds URL query string Uses URLSearchParams — skips any filter with value 'all'. Axios sends GET http://localhost:8001/api/orders?warehouse=London&status=Shipped.
4
FastAPI receives and filters in-memory data apply_filters() applies warehouse, category, status (case-insensitive). filter_by_month() handles direct months (2025-03) and quarters (Q1-2025 → 3 months). Filters are AND-combined sequentially.
5
Pydantic validates and serializes response FastAPI validates the filtered list against the response model (e.g. List[Order]) and returns JSON.
6
Vue renders the result Component stores response in a ref (e.g. allOrders.value). Derived data (totals, charts) uses computed() properties. Template renders with v-for using unique keys.

Filter System

Time Period

Composable ref: selectedPeriod

Query param: ?month=

Values: all, 2025-01…2025-12

Also supports: Q1-2025 through Q4-2025

Applied to: Orders, Dashboard

Location (Warehouse)

Composable ref: selectedLocation

Query param: ?warehouse=

Values: all, San Francisco, London, Tokyo

Applied to: Inventory, Orders, Dashboard

Category

Composable ref: selectedCategory

Query param: ?category=

Values: all, Circuit Boards, Sensors, Actuators, Controllers, Power Supplies

Case-insensitive match

Applied to: Inventory, Orders, Dashboard

Order Status

Composable ref: selectedStatus

Query param: ?status=

Values: all, Delivered, Shipped, Processing, Backordered

Case-insensitive match

Applied to: Orders, Dashboard
